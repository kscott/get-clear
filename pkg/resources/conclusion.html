Almost there

Get Clear is installed. Open a new terminal window and run:

  1. Connect mail
    Run mail setup and follow the prompts to connect your mail account.
  2. Name your calendars
    Run calendar setup to define named groups like work and personal.

Each tool will ask for macOS permissions on first use — just approve them:

reminders list  ·  calendar today  ·  contacts lists  ·  text open

Full guide: github.com/kscott/get-clear
